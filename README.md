# Portfolio

A minimal, responsive single-page portfolio built with React and Vite.

## Features

- Clean white-dominant design with blue accents and black text
- Helvetica font family
- Project categories: Web Development, Jersey Designs, Logo Designs, Thumbnail Designs, Clothing Designs, Other Designs
- Tools & Technologies section
- Smooth hover and scroll transitions
- Fully responsive (mobile, tablet, desktop)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Customization

- **Your name & email**: Edit `src/components/Hero.jsx` and `src/components/Contact.jsx`
- **Projects**: Edit `src/data/projects.js` — add, remove, or update projects per category
- **Tools**: Edit `src/data/tools.js`
- **Colors**: Adjust CSS variables in `src/index.css` (`:root` block)

## Build for Production

```bash
npm run build
npm run preview
```
